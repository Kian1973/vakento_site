# Vakento homepage v2

Standalone front-end concept for a clearer Vakento marketing homepage.

## Included
- Stronger hero: from request to payment / one workplace
- Clear feature explanations instead of abstract menu labels
- Workflow section
- Vakento Assistant concept, clearly marked as in development
- Trade / target audience section
- Future feature roadmap, clearly marked as planned rather than live
- Pricing card using €29/month and 5 GB cloud
- Responsive mobile layout

## Important before live deployment
1. Verify the existing live routes for `/login`, `/registreren`, `/privacy`, `/voorwaarden`, `/contact`.
2. Verify which listed current features are actually available in production.
3. Do not advertise planned functionality as live until its backend is implemented.
4. Merge into the actual Vakento codebase rather than replacing the application shell blindly.
